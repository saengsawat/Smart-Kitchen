## Wire shape of expiresAt
`InventoryLotDto.expiresAt` and `earliestExpiresAt` are `string | null`, produced by the API with `toISOString()` (full UTC instant, e.g. "2026-10-01T00:00:00.000Z"). Fixtures use the same shape. Date-only strings are handled anyway and tested.
