# BUG-007 worker report

Branch `ticket/BUG-007`. Sonnet.

## Cause

The dark circle is the Home header account button (M3-T6, 44 px espresso circle, no letters). `HomeScreen` header used a fixed `paddingTop: spacing.xl` (24) and never read the top safe-area inset. Android status bars and camera cutouts are often taller than 24 dp, so the circle drew under the status bar. Note: no other screen reads the top inset either (BUG-003 only handled the bottom); they use the same fixed `spacing.xl` and are only clear on devices with a short status bar. Not touched here (out of scope); worth a follow-up ticket for S4/S5/S6/S11/S12/Add headers (see `inventory.tsx`, `legend.tsx`, `profile.tsx`, `add.tsx` headers).

## Change

- `apps/mobile/src/screens/HomeScreen.tsx`: header `paddingTop` is now `insets.top + spacing.md` via `useSafeAreaInsets()` (the fixed `spacing.xl` removed from the static style). No other Home change; still a placeholder.
- `apps/mobile/src/screens/HomeScreen.test.ts`: new test mocks the safe-area hook with top 40 and asserts the header's paddingTop is `40 + spacing.md`.

## Results

- `pnpm lint`: clean. `pnpm typecheck`: clean. `vitest run apps/mobile`: 906 passed, 7 skipped, 0 failed.
- Not verified on a device (Android Expo Go); the device pass should confirm.
