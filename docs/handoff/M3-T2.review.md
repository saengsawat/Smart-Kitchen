## Findings

**F1 (blocker) The copy scan is blind to JSX text.** `copy-scan.test.ts:104-108` visits only string and template literals; `JsxText` is neither, so the S2 safety paragraph (`allergies.tsx:135-139`) and two S1 paragraphs are unscanned. Mutation: `This food is safe.` in JSX text passes all 22 tests. Fix: a `ts.isJsxText` branch plus a regression test.

**F2 (blocker) Deep link to any non-onboarding route bypasses the gate.** Only `/` is guarded (`index.tsx:36-42`); `/inventory`, `/menu`, `/shopping`, `/add` render unconditionally and `app.json` sets scheme `smartkitchen` and enables web. Bounded today (inert placeholders), live the moment M3-T3 puts inventory behind `/inventory`. Fix: resolve the route once in `_layout.tsx` and redirect any non-onboarding pathname while the gate is open; pure test over (route, pathname).

**F3 (major) `@types/node` globals leak program-wide.** The `/// <reference types="node" />` in `copy-scan.test.ts:1` widens the global scope for every file; `process.env.HOME`, `Buffer.from`, `NodeJS.Timeout` typecheck in `validation.ts`. The worker report's containment claim is untrue. Fix: a separate tsconfig for `src/lint-rules/` or an eslint `no-restricted-globals` rule; correct the report.

**F4 (major) Home first-run copy matches neither source.** `HomeScreen.tsx:38` renders "Your kitchen is empty." with a period; prototype v4 has no period plus a body sentence; copy-deck §7 says "Your kitchen is empty, for now." with a different body and button. Also a genuine prototype-vs-deck conflict the worker did not escalate. Fix: architect ruling on precedence (recorded below); render the winning strings; correct the report's provenance claims.

**F5 (major) Severity rows Title-Case labels and rewrite user-entered wording.** `allergies.tsx:401` `textTransform: "capitalize"` yields "Crustacean Shellfish" and mangles USER_DEFINED labels (copy-deck §2: sentence case; the member's own wording). Fix: drop the transform; sentence-case MAJOR labels as the chips do; render USER_DEFINED verbatim.

**F6 (major) The gate refusal is not announced and carries no non-typographic signal.** Plain `<Text>` at `allergies.tsx:194`, no live region, no announcement, weight-only distinction from body copy. Fix: `accessibilityLiveRegion="assertive"` plus `announceForAccessibility`, and a non-colour affordance.

**F7 (major) "Skip preferences" is about 16px tall** (`allergies.tsx:167-173`), the one 44pt miss on both screens. Fix: `hitSlop={15}` or a 44pt wrapper.

**F8 (minor)** The none option's confirmed state is colour-only (checkmark always rendered). Fix: render the check only when confirmed.

**F9 (minor, architect-facing)** `client.ts:251` infers `noneConfirmed` from an empty array: an inference of a safety declaration. Fix by contract: explicit `noneConfirmed` on the port.

**F10 (minor)** S1 errors are styled like labels; the no-danger, no-rose decision is right, but nothing replaced the colour. Fix: icon or `sand2` container.

**F11 (minor)** 22 em dashes in the worker report (rule 31). Source comments also carry some; flagged for a ruling.

**F12 (minor)** Forbidden list lacks bare `guarantee` (copy-deck §10).

**F13 (minor)** No loading or error states; `runContinue` has try/finally with no catch (P8).

**F14 (minor)** M3-T1's per-row `householdId` assertion was removed without replacement (rule 13).

**F15 (minor)** Lockfile carries an incidental `@types/react` dedupe. **F16 (minor)** `packages/contracts/src/household.test.ts` outside the enumerated scope (rule 13 defensible; ratify). **F17 (minor, untestable)** Hardware back and edge swipe unverified without a device.
