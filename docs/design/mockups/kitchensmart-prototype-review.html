How to use this deck

Start with the product story

The screens are sequenced like a real household journey, not by implementation order.

1 · Orient

Home → Inventory → Add Food. Confirm whether the dashboard is the right front door.

2 · Capture

Barcode match, no match, manual entry, and item corrections. Check whether provenance feels understandable.

3 · Decide safety

Allergies, profile visibility, recipe verdicts, and blocked states. These are policy decisions wearing UI clothes.

4 · Close the loop

Menu (tonight and planned) → recipe → cook confirmation → shopping → assistant. Confirm what belongs in MVP versus later.

Meeting rule: react to the decision and user flow, not typography polish. “Would we ship this behavior?” is the useful question.
